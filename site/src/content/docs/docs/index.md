---
title: Battistics documentation
description: How to install Battistics, read your Mac's battery and keep the Mac awake.
---

Battistics is a menu bar app for Apple Silicon Macs on macOS 14 or later. It shows what macOS knows about the battery and keeps the Mac awake when you need it, with the lid open or closed.

- New here? Start with [Install](/docs/install/), then the [menu bar](/docs/menu-bar/).
- Want to know what a number means? See [Battery readings](/docs/battery/readings/).
- Keeping a build or a download running overnight? See [Keep Awake modes](/docs/keep-awake/modes/).
- Running it from a terminal or an AI client? See [Automation](/docs/automation/terminal/).

The first launch opens an eight-step tour of Overview, Power, Notifications, History and Help. It never changes a setting, and you can replay it from **Help**.
